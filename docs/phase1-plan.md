Architecture decisions (Claude, within the approved plan):
- The 64 Katalon scripts became **step functions** (`support/katalon/steps`), generated by the converter; the KAT
  specs call them (parity: 64/64 bodies identical to baseline, checked 2026-11-23). Flows reuse the verified logic
  instead of rewriting it; steps move to typed role-based code module by module, each behind a parity run.
- Registry in JSON (`registry/`), state in JSON files (`.data/`), CLI in plain Node (`cli/qa.mjs`): no new packages.
- One worker by default; a flow is a serial describe block; one run at a time per tester (`active-run.json`).
