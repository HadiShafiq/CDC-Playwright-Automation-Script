# Original scripts (frozen)

Copies of every automation script as it was at commit `1a96d4c` (tag `baseline/katalon-64`), grouped by
procurement module. `manifest.json` maps each script to its module and source path.

- **Never edit or run these copies.** They are the reference for parity checks and rollback.
- The runnable originals stay where they were: `tests/katalon/**` (generated by `scripts/katalon/convert.mjs`),
  `tests/mof*/**` and `tests/smoke/**`.
- They are excluded from `tsc` (tsconfig `exclude`) and from Playwright (`testDir` is `tests/`).

| Folder | Module | Scenarios |
|---|---|---|
| `sq/` | Simple Quote | KAT-021, 022, 036, 037 |
| `dp/` | Direct Purchase (RN, Add to Cart, Compare/PI, PR, Assign Code) | KAT-023, 024, 028..035, 038, 039 |
| `direct-loa/` | Direct LOA (PK7 QT, zonal, open; LOA from RN; supplier; DO verify) | KAT-001..020, 025..027 |
| `ct/` | Contract (FD, Agreement, Amendment) | KAT-040..045 |
| `fl/` | Fulfilment (non-contract and contract) | KAT-046..064 |
| `mof/` | MOF supplier (outside the five modules) | KAT-065, REG, CAT, SC |
| `shared/` | Portal smoke | — |

Rollback of any refactored file: `git checkout baseline/katalon-64 -- <path>`.
